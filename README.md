# Mohankumar Markuli Chandrayigowda - Personal Portfolio

Welcome to the repository for my personal portfolio and website. This project showcases my work as a Software Engineer and AI Developer, specializing in building responsive web applications, analytics-oriented backend systems, intelligent RAG pipelines, and conversational chatbot solutions.

## Overview

This website serves as a central hub for my professional identity, containing:
- **About Me**: Background, education (MSc in Business Analytics), and my focus in tech.
- **Skills**: A categorized breakdown of the technologies I work with.
- **Experience**: My professional timeline and career progression.
- **Projects**: Highlights of my technical projects and reports.
- **Blog**: Articles focusing on AI ethics, big data, EV tech, and database systems.
- **Gallery**: A collection of university, work, and network photos.
- **Feedback & Contact**: Channels to read/write feedback or get in touch for hiring.

## Tech Stack

This project is built using modern web technologies:
- **Framework**: [Next.js](https://nextjs.org/) (React)
- **Styling**: Custom CSS and interactive canvas elements for dynamic visual effects
- **Markdown Parsing**: `gray-matter` and `marked` for blog/project content rendering
- **Syntax Highlighting**: `highlight.js` for code blocks in articles

## Getting Started

To run this project locally, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mohankumar-markuli/portfolio.git
   cd portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. **Open your browser:**
   Navigate to [http://localhost:3000](http://localhost:3000) to view the application.

## Features

- **Interactive Canvas Background**: Features a custom, physics-based starry sky with a repelling effect tied to cursor movement.
- **Responsive Design**: Carefully crafted to look great on desktop, tablet, and mobile devices.
- **Markdown Blog Engine**: Automatically parses local markdown files to serve fast, static blog posts with code highlighting.
